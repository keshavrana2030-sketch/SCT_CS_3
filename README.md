# SCT_CS_3 - Image Encryption Tool

##  Project Overview

This project develops an Image Encryption Tool using Python that secures digital images through pixel manipulation techniques. The application encrypts images by applying mathematical operations to pixel values and decrypts them back to their original form using the same secret key. This project demonstrates the basic concepts of image cryptography and secure image processing.
---

##  Objective

To develop an Image Encryption Tool that encrypts and decrypts images using pixel manipulation techniques and demonstrates the fundamentals of image security and cryptography.
---

##  Tools & Technologies Used

- Python
- Pillow (PIL) Library
- Visual Studio Code
- RGB Pixel Manipulation
- Mathematical Operations on Pixels

---

##  Dataset

The project uses user-provided image files such as JPG, JPEG, or PNG formats for encryption and decryption.

### Supported Formats:
- JPG
- JPEG
- PNG
---

##  Workflow

### Image Input
- Load the image using the Pillow library.
- Read image dimensions and pixel values.

### Data Preprocessing
- Encoding categorical variables
- Feature selection
- Train-test split

### Image Encryption
- Apply a secret key to RGB pixel values.
- Modify each pixel using mathematical operations.
- Generate an encrypted image.

### Image Decryption
- Use the same secret key.
- Reverse the mathematical operation.
- Restore the original image.

### Output Generation
- Save the encrypted image.
- Save the decrypted image.

---

##  Results

- Successfully encrypted images using pixel manipulation.
- Generated encrypted images with altered pixel values.
- Successfully decrypted encrypted images back to their original form.
- Demonstrated secure image transformation using a secret key.

---

##  Key Insights

- Pixel manipulation can be used as a basic image encryption technique.
- Encryption transforms image data into an unreadable format.
- Decryption restores the original image using the same key.
- Secret keys play an important role in maintaining image security.\
- Image encryption is widely used for protecting confidential visual information.
